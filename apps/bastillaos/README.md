# BastillaOS

Jedyny pulpit systemu, dostępny pod głównym adresem `/`. Korzysta z tego samego
serwera API. Aktywna nawigacja obejmuje pulpit z czatem, flotę, diagnostykę,
procesy i naprawy oraz HyperCom. Moduł migawek i przywracania został usunięty.

Tożsamość systemu operacyjnego: Debian 13 Stable (Trixie) amd64 + KDE Plasma.
Powtarzalny build live/install ISO opisano w `bastillaos/README.md`.
